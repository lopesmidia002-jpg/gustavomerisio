# Diretrizes do Projeto Brasa Studio (Memória Operacional)

## Protocolo de Trabalho Obrigatório

1. **Atualização de Documentação a Cada Entrega:**
   - Ao final de toda feature, correção de bug ou melhoria, atualize obrigatoriamente os arquivos:
     - `DOCUMENTACAO.md`
     - `PASSOS.md`
     - `CONTEXTO.md`

2. **Avanço Passo a Passo Sob Demanda:**
   - Execute apenas o passo atual aprovado pelo usuário.
   - Atualize os checkboxes `[x]` em `PASSOS.md`.
   - **NUNCA** inicie o próximo passo automaticamente. Aguarde autorização explícita do usuário ("só inicie o próximo passo quando eu pedir").

3. **Texto de Commit ao Final de Cada Interação:**
   - Sempre forneça no final da resposta uma sugestão de mensagem de commit formatada conforme o padrão *Conventional Commits*.

4. **100% no Docker:**
   - Todos os serviços, servidores de desenvolvimento e visualização devem ser executados através do Docker / Docker Compose.

5. **Identidade Visual e Fidelidade Extrema:**
   - Landing page inspirada na Brasa Studio: estética premium, dark (#050505), superfícies acetinadas (#0B0B0B e #101010), acentos em laranja brasa (#FF4B19), tipografia editorial moderna e fotografia cinematográfica com iluminação quente.
